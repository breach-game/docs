# Mockups

Live source: https://claude.ai/artifact/8XUMf2dB8tUQEtf56QHsCw

- `Boot.dc.html`: title screen (language, NPC brain)
- `Main.dc.html`: LR-OS desktop during mission 3
- `BlueTeam.dc.html`: SOC console in Blue Team mode
- `Map3D.dc.html`: 3D network map
- `Tunnel3D.dc.html`: mission 6, 3D exfiltration
- `canvas.json`: layout of the boards in the canvas

These files use the Claude Design canvas format (`.dc.html`). Read them as a reference for layout, colours and content, not as code to reuse as is. The text inside the mockups is in French.
